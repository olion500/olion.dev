Principles

  1. olion makes software for one person at a time. Usually, that person is us. We take the chores out of everyday life, so you get more time for what you love. Nothing has launched yet. These are the principles we build by.

  2. We start with the smallest thing that works, usually a single browser page. We use it for a day and fix what annoys us. If we keep coming back, it earns the next step.

    Small scope, not low quality.

  3. We build what we need ourselves. Before asking if there's a market, we ask if we'd open it again tomorrow. If we wouldn't, we don't ship it.

  4. When something good already exists, we rebuild it first. Copying shows us which details matter. Then we add our own.

    We copy to learn, not to take credit.

  5. A hunch is where we start, not where we decide. We test it against past data, a quick experiment, or a day of real use. If the result disagrees, the result wins.

  6. We do a task by hand once to understand it. The second time, we automate it. Fetching data, running numbers, remembering settings: a machine can do all of it. You keep the parts worth doing.

  7. A finished small thing beats an unfinished big one. We write the description, take the screenshots, and set up a way to report bugs. The last 10% is boring. We finish it anyway.
